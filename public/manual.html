01 System Overview
QABBAN OS is a fully integrated, cloud-native roastery operating system for Saudi specialty coffee producers and buyers.
🏭
Roaster Admin Portal
Full inventory management, branch humidity monitoring, financial intelligence, and order fulfilment workflow.
☕
Cafe (Buyer) Portal
Coffee catalog with tier-based pricing, bean requests, loyalty tracker, and order history for Saudi roasteries.
🌍
Global Exchange
International green-bean sourcing marketplace with Spot & Forward contracts, climate passports and ship tracking.
🏅
Coffee Miles Loyalty
Bronze / Silver / Gold tier system with automatic tier assignment, hybrid stacked discounts and milestone nudges.
📊
QFI Financial Engine
Reactive portfolio financials with per-tier wholesale pricing, live margin configuration and environmental P&L.
🧾
ZATCA Phase-2
UBL XML e-invoicing, bulk shrinkage report, and 15% VAT compliance for Saudi tax authority requirements.
🧪
Sponge Effect Engine
Dynamic yield coefficient that adjusts the 0.82 roasting baseline based on real warehouse humidity.
💱
XE Currency Engine
Live USD/EUR→SAR conversion via XE Currency API with SAMA peg, configurable buffer and 60s execution lock.

  • Global Exchange Currency Settings — XE live rates + buffer + refresh
  • Live Balance Banner — purchased green kg vs dispatched equivalent
QFI Wholesale Price Formula
// True Roasted Cost trueRoastedCost = costPerKg / 0.82 // Wholesale Price per Tier wpBronze = trueRoastedCost × (1 + 40% / 100) wpSilver = trueRoastedCost × (1 + 35% / 100) wpGold = trueRoastedCost × (1 + 28% / 100)
Margin Input Panel (SET ALL)

Clicking SET ALL broadcasts via BroadcastChannel to all open cafe portals, updating wholesale prices in real-time across all browser tabs.

07 Admin Portal — Bean Requests Tab
Route: /admin/requests — Incoming bean requests, dispatch queue, and roasting interest pre-orders.
Request Status Workflow
PENDING CONFIRMED DISPATCHED or CANCELLED
DISPATCH auto-updates Coffee Miles Tier: When a request is dispatched, lifetimeKgPurchased += dispatchedKg and coffeeMilesTier is recalculated automatically. No manual intervention required.
Roasting Interests (Pre-Orders)

When a cafe requests beans for an OUT OF STOCK origin, a Roasting Interest record is created. Admin sees these in a separate table with MARK SEEN and SCHEDULE actions to plan the next roast batch.

21 Sponge Effect — Dynamic Yield Engine
Dynamically adjusts the 0.82 roasting shrinkage baseline based on real warehouse humidity, affecting inventory value and environmental P&L.
RuleConditionΔFinal CoefficientEffect
Rule A — Moisture Absorption RH > 70%+0.005 0.825 Beans heavier → less shrinkage → GAIN
Baseline 20% ≤ RH ≤ 70%0 0.820 Standard 18% shrinkage
Rule B — Evaporation Loss RH < 20%−0.003 0.817 Beans lighter → more shrinkage → LOSS
Environmental P&L Calculation
spongeKgDelta = (spongeCoeff - 0.82) × greenKg environmentalPnL = spongeKgDelta × wpGold (SAR/kg) // Positive = moisture gain (more saleable weight) // Negative = evaporation loss (less saleable weight)

23 SFDA Recall & Audit Shield
SFDA Article 18 compliance with lot-level sack photo traceability and real-time cafe recall notifications.
Recall Workflow
  • Admin clicks "INITIATE RECALL" on lot → SFDA Recall Modal
  • Enters recall instructions; system shows all cafes with DISPATCHED orders
  • Confirms → POST /admin/inventory/:lotId/recall → status = RECALLED
  • Affected cafes see urgent red banner on next portal load (checked every 1 min)
  • Cafe staff acknowledges banner → dismissed, logged
Recalled lots are BLOCKED — cannot be ordered, excluded from financial calculations, shown with red "RECALLED — BLOCKED" overlay in all views.
24 Bilingual Engine (EN / AR)
Full bilingual support — English and Arabic with RTL layout toggle. All UI text translated via data-i18n attribute engine.
Coverage: Navigation, page titles, stat labels, table headers, button labels, modal text, form labels, climate terms, risk levels, lot card labels, financial labels, recall notifications, orders page — all bilingual.

Language preference is persisted in localStorage. Switching triggers instant re-render with no page reload. Arabic layout uses <html dir="rtl"> for full RTL support including reversed navigation order.
